# 傅立叶级数PulseWave.md

## 公式

$$
\boxed{
\begin{aligned}
a_0 &= \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\,dx \\[4pt]
a_n &= \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\cos nx\,dx \quad (n\ge 1)\\[4pt]
b_n &= \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\sin nx\,dx \quad (n\ge 1)
\end{aligned}
}
$$

## 4 脉冲 Pulse Wave

（傅立叶级数-脉冲）设 $f(x)$ 是周期为 $2\pi$ 的周期函数，它在 $[-\pi,\pi]$ 上可看作宽度 $\varepsilon\to 0$ 的矩形脉冲：

$$
f(x)=
\begin{cases}
\frac{1}{\varepsilon},&|x|<\frac{\varepsilon}{2},\\[6pt]
0,&\text{其他}.
\end{cases}
$$

将 $f(x)$ 展开成傅立叶级数。

解：函数是奇函数，所以 $a_0=a_n=0$，

同时

$$
b_n=\frac{2}{n\pi}\sin\frac{n\varepsilon}{2}\xrightarrow[\varepsilon\to 0]{}\frac{1}{\pi},\quad n=1,2,3,\cdots
$$

由于

$$
f(x)=\frac{a_0}{2}+\sum_{n=1}^{\infty}(a_n\cos\,nx+b_n\sin\,nx),\,x\in C
$$

即

$$
f(x)=\frac{2}{\pi}\sin x+\frac{2}{\pi}\sin 2x+\frac{2}{\pi}\sin 3x+\cdots+\frac{2}{\pi}\sin nx+\cdots
$$
（注：用此展开制作图像；各次谐波等幅叠加，逼近周期脉冲）

### 实体

```phymodel

Group(name: "FourierPulsePhasors", position: (0, 0, 0)) {
    Repeat(4) { i in
        CAD()
        .name("sphere[i]")
        .mesh(commands: [
            "DEF sphere = SOLID_FORMULA 0,0,0 (x/0.006)^2+(y/0.006)^2+(z/0.006)^2-1=0",
        ])
        .material(red: 0.67, green: 0.32, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
        .position(x: -0.5 + 0.4/pi * ((i >= 1 ? 1 : 0) + (i >= 2 ? 1 : 0) + (i >= 3 ? 1 : 0)), y: 1.5, z: 0.0)
    }
    CAD()
    .name("sphere4")
    .mesh(commands: [
        "DEF sphere = SOLID_FORMULA 0,0,0 (x/0.006)^2+(y/0.006)^2+(z/0.006)^2-1=0",
    ])
    .material(red: 0.67, green: 0.32, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
    .position(x: -0.5 + 0.4/pi * 4, y: 1.5, z: 0.0)
    .trail(style: .line, lifeSpan: 3.0, size: 0.002, color: [1.0, 0.4, 0.2], opacity: 0.8)
    Repeat(4) { i in
        Graph()
        .name("Circle[i]")
        .mesh(x: "2/pi*10*cos(t)", y: "2/pi*10*sin(t)", z: "0", t: "[0,2*pi]", radius: 0.002)
        .material(red: 0.46, green: 0.2, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
        .position(x: -0.5 + 0.4/pi * ((i >= 1 ? 1 : 0) + (i >= 2 ? 1 : 0) + (i >= 3 ? 1 : 0)), y: 1.5, z: 0.0)
    }
}

Line()
.name("connectLine")
.mesh(radius: 0.002, through: ["sphere0", "sphere1", "sphere2", "sphere3", "sphere4"])
.material(red: 0.1, green: 0.9, blue: 0.1, opacity: 1, roughness: 0.5, metallic: 0.8)

Line()
.name("connectLinePulse")
.mesh(radius: 0.002, through: ["sphere4", "spherePulse"])
.material(red: 0.8, green: 0.1, blue: 0.1, opacity: 1.0, roughness: 0.5, metallic: 0.8)

CAD()
.name("spherePulse")
.mesh(commands: [
    "DEF sphere = SOLID_FORMULA 0,0,0 (x/0.01)^2+(y/0.01)^2+(z/0.01)^2-1=0",
])
.material(red: 0.9, green: 0.1, blue: 0.1, opacity: 1, roughness: 0.5, metallic: 0.8)
.position(x: 0, y: 1.5, z: 0.0)

Graph()
.name("PulseY")
.mesh(x: "0", y: "(40/pi)*(sin(t)+sin(2*t)+sin(3*t)+sin(4*t))", z: "0", t: "[0,2*pi]", radius: 0.005)
.material(red: 0.46, green: 0.2, blue: 1.0, opacity: 0.0, roughness: 0.5, metallic: 0.8)
.position(x: 0.0, y: 1.5, z: 0.0)

Graph()
.name("Pulse")
.mesh(x: "10t", y: "(40/pi)*(sin(t)+sin(2*t)+sin(3*t)+sin(4*t))", z: "0", t: "[0,2*pi]", radius: 0.005)
.material(red: 0.46, green: 0.2, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
.position(x: 0.0, y: 1.5, z: 0.0)

Text()
.name("text_run")
.mesh(text: "运行", extrusionDepth: 0.02, fontSize: 0.1)
.physic(mass: 0.1, staticFriction: 0.9, dynamicFriction: 0.75, restitution: 0.22, mode: .kinematic)
.material(red: 0.2, green: 0.8, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
.position(x: -0.2, y: 1.7, z: 0.0)

```
