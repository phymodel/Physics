位移图像

## 位移图像

- 坐标系：坐标原点、正方向、单位长度、物理量、物理量的单位.
- $\Delta x$ 为正：若两坐标之差为正，则位移的方向指向 $x$ 轴的正方向.
- $\Delta x$ 为负：若两坐标之差为负，则位移的方向指向 $x$ 轴的负方向.
- 位移大小：有向线段的大小.
- 位移方向：有向线段的方向.
- 矢量：既有大小又有方向（位移）.
- 标量：只有大小没有方向（时间、路程）.
- 路程：物体运动轨迹的长度，$s=\sum \lim_{\Delta t\to 0}|v\Delta t|$（瞬时速率 ）$v$.

### 实体_坐标系

```phymodel

Latex()
.name("coordinateSystemName")
.mesh(width: 0.2, text: ¥¥
<center>
<span style="font-size: 60px;">坐标系</span>
</center>
¥¥
)
.material(red: 1.0, green: 1.0, blue: 1.0, opacity: 0.999, roughness: 0.5, metallic: 0.8)
.physic(mass: 0.1, staticFriction: 0.9, dynamicFriction: 0.75, restitution: 0.22, mode: .kinematic)
.position(x: -0.8, y: 1.6, z: 0.0)

// 打组系统（坐标系）
Group(name: "CoordinateSystem", position: (0.0, 1.5, 0.0), gesture: false) {
    // 坐标系主体
    
    CAD()
    .name("CoordinateSystemBodyArrow")
    .mesh(commands: [
        "DEF arrow = PATH_OPEN 0,0,0 Z 2.0,0 1.9,-0.03 1.9,-0.005 0,-0.005 0,0  REV X 360"
    ])
    .material(red: 0.5, green: 0.5, blue: 0.5, opacity: 1, roughness: 0.3, metallic: 0.9)
    .physic(mass: 0.5, staticFriction: 0.6, dynamicFriction: 0.4, restitution: 0.2, mode: .kinematic)
    .position(x: -1.0, y: 0.0, z: 0.0)
    .gesture(false)
    
    Text()
    .name("physicalQuantity")
    .mesh(text: "x", extrusionDepth: 0.001, font: "Times New Roman Italic", fontSize: 0.05)
    .material(red: 0.9, green: 0.1, blue: 0.3, opacity: 1, roughness: 0.5, metallic: 0.8)
    .physic(mass: 0.3, staticFriction: 0.6, dynamicFriction: 0.4, restitution: 0.2, mode: .kinematic)
    .position(x: 0.9, y: -0.08, z: 0.0)
    .gesture(false)
    
    Text()
    .name("unitOfPhysicalQuantity")
    .mesh(text: "/m", extrusionDepth: 0.001, font: "Times New Roman", fontSize: 0.05)
    .material(red: 0.9, green: 0.1, blue: 0.3, opacity: 1, roughness: 0.5, metallic: 0.8)
    .physic(mass: 0.3, staticFriction: 0.6, dynamicFriction: 0.4, restitution: 0.2, mode: .kinematic)
    .position(x: 0.94, y: -0.08, z: 0.0)
    .gesture(false)
    
    // 批量生成元素（刻度）
    Repeat(8) { i in
        CAD()
        .name("CoordinateSystemEllipsoid[i]")
        .mesh(commands: [
            "DEF sphere = SOLID_FORMULA 0,0,0 (x/0.02)^2+(y/0.02)^2+(z/0.02)^2-1=0",
        ])
        .physic(mass: 0.6, staticFriction: 0.6, dynamicFriction: 0.4, restitution: 0.2, mode: .kinematic)
        .material(red: 0.67, green: 0.32, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
        .position(x: -0.8 + i * 0.2, y: 0.0, z: 0.0)
        .gesture(false)
    }
    
    Repeat(8) { i in
        Text()
        .name("CoordinateSystemText[i]")
        .mesh(text: "[i-2]", extrusionDepth: 0.001, font: "Times New Roman", fontSize: 0.05)
        .material(red: 0.9, green: 0.1, blue: 0.3, opacity: 1, roughness: 0.5, metallic: 0.8)
        .physic(mass: 0.3, staticFriction: 0.6, dynamicFriction: 0.4, restitution: 0.2, mode: .kinematic)
        .position(x: -0.8 + i * 0.2, y: -0.08, z: 0.0)
        .gesture(false)
    }
    
}

```

### 触发系统_位移为正

```phymodel

Behavior()
.name("TapDeltaXPositive")
.trigger{
    Tap(){
        objects: ["DeltaXPositive"]
    }
}
.actions{
    Show(1){
        objects: ["DeltaXPositiveArrow"]
        motionType: .pop
        duration: 0.2
    }
    Speak(2){
        object: "DeltaXPositive",
        volume: 0.5,

    }

        objects: ["DeltaXPositiveArrow"]
        motionType: .scale
        duration: 2.0
    }
}

```
